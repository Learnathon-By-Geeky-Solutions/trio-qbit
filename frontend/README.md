# Frontend - React (Router V7)

## Folder Structure

```
frontend/
```

## Description [Short]

React Router V7 is launched as a complete framework to build robust, data-driven `react` applications. Actually it is pre-configured with `vite` by default this configuration comes up with `tailwindCSS` and `TypeScript`.
